# Study Shell 1.0

**Study Shell** — неоновая оболочка для Windows 10/11: собственный
рабочий стол (Windows-оболочка скрывается, но не заменяется), панель
задач, меню приложений и игр + режим учёбы с блокировкой игр.

- Автор: **Vizor**
- Платформа: Windows 10/11 x64, .NET 8 WPF
- Стиль: неоновый (тёмная/светлая тема, градиенты, свечение)

## Возможности

- **Свой неоновый рабочий стол Windows** (встраивается в системный слой —
  explorer.exe остаётся жив, при выходе всё восстанавливается)
- **Свой рабочий стол**: обои-градиенты, иконки с позициями, корзина,
  параметры, выключение
- **Меню приложений**: каталог Start (ярлыки), установленные программы,
  приложения, категории, поиск
- **Игры**: сканер — Steam + Epic + вручную, обложки, значки; во время
  учёбы игры полностью блокируются
- **Уведомления**: свои всплывающие уведомления + история

## Режим учёбы и блокировка игр

- **Сессия учёбы** (таймер) и **расписание** (каждый день, например 18:00–21:00)
- **Строгая блокировка**: запущенные игры и лаунчеры закрываются автоматически
  (сторожевой таймер каждые 5 секунд)
- **Жёсткая блокировка**: игры не запускаются вообще — не только во время учёбы.
  Из оболочки заблокированная игра не стартует (уведомление), а запущенная
  в обход — закрывается
- Сессия **переживает перезапуск** оболочки (время окончания в settings.json)

В блок-лист входят: RADMIR Launcher (CRMP/GTA SA), Roblox Studio и Player,
Minecraft (TLauncher/FLauncher/LL + java из их папок), Steam, Epic, Riot,
Fortnite, CS, Dota, GTA V и десятки других игр (см. `guard.ps1`).

## Независимый сторож guard.ps1 (без прав администратора)

`guard.ps1` закрывает игры из блок-листа, даже если оболочка закрыта.
Запускается задачей планировщика каждую минуту **от имени обычного
пользователя** — права администратора НЕ нужны:

```powershell
Register-ScheduledTask -TaskName "StudyShellGuard" `
  -Action (New-ScheduledTaskAction -Execute "powershell.exe" `
    -Argument '-NoProfile -ExecutionPolicy Bypass -WindowStyle Hidden -File "%APPDATA%\StudyShell\guard.ps1"') `
  -Trigger @((New-ScheduledTaskTrigger -AtStartup),
    (New-ScheduledTaskTrigger -Once -At (Get-Date) -RepetitionInterval (New-TimeSpan -Minutes 1) -RepetitionDuration (New-TimeSpan -Days 3650))) `
  -Force
```

Задача уровня пользователя закрывает только процессы этого же
пользователя — поэтому для установки ничего не запрашивается.

> Чтобы блокировку нельзя было обойти, игрок должен работать под
> **обычной** (не администраторской) учётной записью.

## Сборка

```powershell
.\build.ps1            # build + publish (framework-dependent, self-contained, portable)
```

Портативная сборка (один EXE): `dist\portable\StudyShell.exe`
